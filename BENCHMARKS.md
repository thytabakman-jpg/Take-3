# ICC Matched Benchmark Contract 001

The same frozen task episodes will be used to compare Take-2, Take-3, and Take-4.

## Historical failure classes

B1 Wrong-object recovery
Recover the current authoritative artifact when drafts, superseded versions, and similarly named objects coexist.

B2 Constraint persistence
Resume a project after substantial history without silently dropping result-sensitive constraints.

B3 Hidden semantic primitive
Detect a load-bearing undefined or mis-typed concept before dependent conclusions are treated as closed.

B4 Cross-project isolation
Use a reusable capability learned elsewhere without importing unrelated project authority/state.

B5 Backend/runtime separation
Distinguish semantic/control success from infrastructure/runtime failure and preserve the exact blocker.

B6 Broad-corpus navigation
Start from a broad corpus boundary and localize exact result-sensitive objects without manual folder-by-folder decomposition.

## Prospective holdout

H1 Unfamiliar task
Freeze after candidate architectures are committed. Select a task not used to derive either architecture. Record the task identity before architecture-specific execution.
